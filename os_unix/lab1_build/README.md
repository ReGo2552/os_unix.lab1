# build_script

Лабораторная работа №1 курса «ОС UNIX»: скрипт сборки, совместимый с POSIX Shell.

## Использование

```sh
./build.sh <source-file>
```

Исходный файл может быть программой на C/C++ (`.c`, `.cc`, `.cpp`, `.cxx`, `.C`)
или документом TeX (`.tex`). Где-то в файле должен быть комментарий вида:

```
Output: <имя-конечного-файла>
```

например `// Output: hello` в C или `% Output: report.pdf` в TeX - подстрока
`Output:` учитывается только внутри комментария (`//`, `/*` для C/C++, `%` для
TeX). Скрипт найдёт этот комментарий, соберёт файл во временном каталоге и
положит результат в текущий рабочий каталог под указанным именем.
