# UNIX, лабораторная №3: жёсткие ссылки

Программа рекурсивно собирает файлы и читает их содержимое в строки.
`unordered_map` вычисляет хэши строк через `std::hash` и сравнивает содержимое
при коллизиях. Дубликаты заменяются жёсткими ссылками. Символьные ссылки
пропускаются.

## Сборка и запуск

Из корня проекта:

```sh
cd labs/os_unix/lab3_hardlinks
c++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o hardlinks
./hardlinks /путь/к/каталогу
```

Проверить inode и количество ссылок у обработанных файлов:

```sh
stat -c '%i links=%h %n' /путь/к/каталогу/*
```

У одинаковых файлов должен совпасть inode. После замены запись через любое
имя меняет общие данные. Во время работы программы файлы не следует изменять.
Каталог должен находиться на одной файловой системе; содержимое уникальных
файлов хранится в памяти. Имя с суффиксом `.hardlink` используется временно:
если оно уже занято, программа завершится с ошибкой, сохранив оба файла.
