# ОС, лабораторная №2: сетевые подключения и сигналы

TCP-сервер принимает одного клиента, остальные соединения сразу закрывает.
Выводит количество полученных байтов и уведомления о SIGHUP.
Ожидание подключений, данных и сигнала выполняется через `pselect()`.

## Сборка и запуск

Из корня проекта:

```sh
cd labs/os/os_lab2_signals
cc -std=c11 -Wall -Wextra -Wpedantic main.c -o server
./server
```

Остановка: `Ctrl+C`.

В другом терминале подключиться к серверу и ввести текст:

```sh
nc 127.0.0.1 8080
```

Отправить сигнал (вместо 12345 указать PID, напечатанный сервером):

```sh
kill -HUP 12345
```
