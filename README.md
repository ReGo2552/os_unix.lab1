# Лабораторные работы

Лабораторные работы по курсам «ОС UNIX» и «Операционные системы».

## ОС UNIX

1. [lab1_build](os_unix/lab1_build/) - скрипт сборки на POSIX Shell.
2. [lab2_concurrent_container](os_unix/lab2_concurrent_container/) - конкурентный контейнер (Docker + flock).
3. [lab3_hardlinks](os_unix/lab3_hardlinks/) - замена одинаковых файлов жёсткими ссылками на C++17.

## Операционные системы

1. [os_lab1_monitors](os/os_lab1_monitors/) - монитор на C с POSIX threads.
2. [os_lab2_signals](os/os_lab2_signals/) - TCP-сервер и обработка SIGHUP через pselect на C.
